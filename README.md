# CodeAlpha Calculator

A modern, responsive calculator built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

* Addition, subtraction, multiplication, and division
* Percentage calculation
* Positive and negative number support
* Decimal number support
* Clear (AC) and Delete (DEL) buttons
* Keyboard support
* Responsive design for mobile and desktop
* Modern dark-themed user interface
* Error handling for division by zero

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_Calculator.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Usage

* Click the number buttons to enter numbers.
* Select an arithmetic operator.
* Press `=` to calculate the result.
* Use `AC` to clear and `DEL` to delete the last digit.
* You can also use your keyboard.
